M5

晶片實作

CNN 晶片與 IoTDF 的 RTL 由本人撰寫

CNN Convolution Accelerator

系統晶片實作專題｜三人｜2024

  • 分工：algorithm design、RTL coding、back-end flow。
  • 64×64 影像依序執行 3×3 Convolution（zero-padding）＋ReLU、2×2 Max-Pooling、Flatten，由 FSM 控制各層 memory 讀寫。
  • Interleave 兩張輸入影像的 pixel stream，單一 memory channel 同時服務兩者，省去額外的 Line Buffer。
  • 以 TSMC 0.13 µm cell library 完成 Logic Synthesis 與 APR（Auto Place & Route），並執行 DRC／LVS。

IoT Data Filtering（IoTDF）

實用數位系統設計 期末專題｜團隊｜課程成績 A+

  • 以 Verilog 撰寫 IoTDF 的 RTL，完成 functional verification 與 logic synthesis。
  • 期末報告以英文撰寫：algorithm、architecture、verification flow、synthesis constraints、coverage check。
