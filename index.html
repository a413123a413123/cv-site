CNN Convolution Accelerator

系統晶片實作專題｜三人｜2024

  • 分工：algorithm design、RTL coding、back-end flow。
  • 64×64 影像依序經過含 zero-padding 的 3×3 Convolution 與 ReLU、2×2 Max-Pooling、Flatten，由 FSM 控制各層 memory 讀寫。
  • Interleave 兩張輸入影像的 pixel stream，單一 memory channel 同時服務兩者，省去額外的 Line Buffer。
  • 以 TSMC 0.13 µm cell library 完成 Logic Synthesis 與 Auto Place & Route，並執行 DRC 與 LVS。
